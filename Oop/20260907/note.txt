==============================

we use MVC architecture in our project which is a design pattern to separate the data, business logic and user interface of our application.
    M = Model ( eg : data class taht contains data and business logic and comiunicate with database )
    V = View ( eg : user interface that displays data to the user and takes input from the user )
    C = Controller ( eg : handles user input and updates the model and view )
    
    |=======================|     |=======================|     |=======================|
    |          View         | <=> |       Controller      | <=> |          Model        |
    |=======================|     |=======================|     |=======================|

===============================

as an example lets create a class called rectangle
    * we create that class in model because it contains data.

in a class there are 3 things 
    * identity
    * data
    * methods

public class Rectangle {
    // data
    int length;
    int width;

    // constructor
    public Rectangle(int length, int width) {
        this.length = length;
        this.width = width;
    }

    // methods
    public int area() {
        return length * width;
    }

    public int perimeter() {
        return 2 * (length + width);
    }

    public void displayData() {
        System.out.println("Length: " + length);
        System.out.println("width: " + width);
    }
}
